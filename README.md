# BMI Calculator

A simple and responsive **BMI Calculator** built using **HTML**, **Tailwind CSS**, and **JavaScript**.

Users can enter their height and weight to calculate their Body Mass Index (BMI) instantly.

---

# Features

- Calculate BMI instantly
- Responsive modern UI
- BMI category detection
- Reset button
- Styled with Tailwind CSS
- External JavaScript file

# How It Works

The user enters:

- Height in centimeters (cm)
- Weight in kilograms (kg)

The application uses the BMI formula:

```text
BMI = weight (kg) / height² (m²)
```

Example:

```text
Height = 170 cm
Weight = 65 kg
BMI = 22.5
```

---

# BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Healthy |
| 25 - 29.9 | Overweight |
| 30+ | Obesity |
